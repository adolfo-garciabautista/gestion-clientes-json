# Gestión de Clientes en Python

Proyecto de consola que permite gestionar clientes usando un archivo JSON como base de datos.

## Funcionalidades

- Mostrar clientes
- Agregar clientes
- Buscar clientes por ID
- Eliminar clientes
- Modificar clientes
- Filtrar clientes por edad

## Tecnologías

- Python
- JSON

## Cómo ejecutar

```bash
python sistema_clientes_json.py
